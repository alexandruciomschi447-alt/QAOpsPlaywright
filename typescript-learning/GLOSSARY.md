# Small glossary

| Word | Meaning |
| --- | --- |
| Variable | A name that holds a value. |
| Type | A description of the values allowed in a place. |
| Parameter | An input name in a function definition. |
| Argument | A real value passed to a function call. |
| Return value | The result a function gives back. |
| Interface | A description of the properties and methods an object needs. |
| Type alias | A name you give to a type. |
| Optional | Allowed to be missing. Written with `?` on a property. |
| Union | A choice between types, written with `|`. |
| Literal | One exact value, such as `"done"`. |
| Narrowing | Checking a value so TypeScript knows a more specific type. |
| Type guard | A function whose result tells TypeScript which type a value has. |
| Generic | A type input that lets a definition work with different types. |
| Constraint | A rule limiting what a generic type input can be. |
| Tuple | An array with known types at particular positions. |
| Promise | A value representing work that will succeed or fail later. |
| Callback | A function passed to other code to be called there. |
| Assertion | A check that something is true. A type assertion using `as` instead tells the compiler to trust you; it does not validate data. |
| Compile | Check or translate source code before it runs. |
| Runtime | The time when code actually runs. |
| Mutation | Changing an existing object or array. |
| Dependency | Another service or function your code needs. |
| Mock | A fake dependency used in a test. |
| Dependency injection | Passing dependencies into code so callers can choose real or fake versions. |
| Discriminant | A shared property with literal values that identifies a union case. |
| Mapped type | A type that visits each property key to describe a new object type. |
| Conditional type | A type that chooses between types using an `extends` condition. |
| Exhaustive check | A check that every possible union case has been handled. |
| never | A type with no possible values. |
| unknown | A value whose type must be checked before use. |
| any | A type that disables many checks. Avoid it in these exercises. |
| Stale | Previously checked files have changed, so the old result needs checking again. |
