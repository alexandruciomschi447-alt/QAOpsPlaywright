# Learning project

This workspace contains a TypeScript learning curriculum in typescript-learning and existing Playwright work. Preserve existing work.

When the learner asks for help with an exercise, explain the concept in simple English and give small hints first. Do not complete the exercise or reveal its solution unless the learner explicitly asks for that. Do not add answer files, reference solutions, or implementation snippets to curriculum documentation.

Keep tests separate from starter code. Do not weaken tests to make an exercise pass. Unfinished starters are intentionally failing. Use `npm run check -- ID` for isolated checks. Use strict TypeScript and deterministic local mocks.
